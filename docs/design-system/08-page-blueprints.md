# Page blueprints

## Homepage

1. Signature hero — één H1 en skydiveconcept.
2. Positionering — “Creatieve groeipartner.”
3. Geselecteerd werk — 3 sterke cases met verschillende competenties.
4. Vijf kernpijlers — compact, visueel, doorlinkbaar.
5. Groei/strategie — alleen geverifieerd bewijs.
6. Persoonlijke aanpak — stappen zonder carousel-afhankelijkheid.
7. Testimonials — echte bron en case-link.
8. Final CTA — één duidelijke kennismaking.

## Diensten

1. Heldere belofte.
2. Flow strategie → content → productie → distributie → groei.
3. Vijf dienstenblokken.
4. Relevante cases per blok.
5. FAQ alleen met echte vragen.
6. CTA.

## Werk

3. Responsive projectgrid.
4. Lege state en reset.
5. CTA.
